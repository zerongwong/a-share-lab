# Contributor Covenant Code of Conduct

We pledge to make participation in A Share Lab respectful and harassment-free for everyone.

Examples of positive behaviour include using welcoming language, accepting constructive feedback,
focusing on reproducible evidence, and respecting data licences and personal privacy. Unacceptable
behaviour includes harassment, publication of private information, sharing credentials or licensed
datasets, and using project channels to promote guaranteed returns or manipulate securities.

Maintainers may remove, edit, or reject contributions and participation that violate these standards.
Security issues and accidental disclosure of sensitive data should be reported privately as described
in `SECURITY.md`.

This policy is adapted from Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
