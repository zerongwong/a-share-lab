# 盘中持仓风险监控

版本 `intraday-holding-stop-monitor-v1`。它是**一分钟轮询**，不是交易所逐笔实时推送、券商条件单或自动交易。
不改变既有策略：新入场结构风险距离 ≤8%；结构先失效可先退出；成本亏损8%为硬预警上限。

## 监控范围与动作

- 仅监控用户确认的当前 1–8 只持仓；未确认买入的推荐组合不是实盘。空仓安静，不抓取全市场。
  `continuous-signal-v3` 数据库迁移不自动停用持仓；必须在使用者明确确认空仓后写入 `cleared` revision。
  本机这次已完成该显式清空，所以在下一次明确确认真实建仓前不监控旧荐股；历史警报与证据仍保留审计。
- 北京时间交易日09:25–11:30、13:00–15:00检查；午休、周末和核验为休市的日期不查询行情。
- 使用腾讯和新浪公开行情，只请求持仓代码。价格须为正且位于日内高低范围内；核验代码、
  行情时间与两源一致性。行情年龄上限90秒，不能用请求时刻替代报价时刻。
- 成本线＝已确认成本×92%，不放松先前记住的成本底线。旧仓可检查当日低价以捕捉轮询间触线；
  当天建仓或更新持仓声明时，只比较最新报价，避免把买入前的日内低点当作持仓亏损。
- 两个新鲜来源各自均显示成本触线，且入场日至当日的公司行动证据完整时，发红色退出风险提示；证据不完整则发
  “疑似触线，立即核验”，不降级成普通持有，也不凭不可比价格确认卖出。
- 公司行动自动核验须单独授权。当天盘中和收盘各自缓存；“无事件/已发现”不重复查询，临时未知按15分钟
  退避且每阶段最多3次，绝不每分钟查询巨潮。外发的唯一持仓字段是六位股票代码；成本、股数、金额、
  权重、名称、入场日和保护线均只留在本机。巨潮异常只让对应股票保持“待核验”，行情止损提醒和整份晚报继续运行。
- 读取先前已核验保护线，不用尚未完成的日周K线重算。盘中触线发“结构风险、待收盘确认”，
  不能把瞬间下探说成已确认形态破坏。盘中不调仓、不改持仓/保护线、不计算或购买替补。
- 只有用户确认卖出后才释放资金；补位仍由收盘后的保留股＋候选＋现金联合评估决定。

## 推送与留痕

仅 Server酱；无图片、Bark、R2、券商接口。明确授权保存在本机监控配置，范围为已登记实际持仓的风险摘要；
这不扩大普通晚报/图片的授权范围。发送前再次核对当前持仓版本及启用授权，已清仓立即停止旧仓披露。
通知不含原始成本、股数、账户金额或权重；包含名称/代码、触线性质、报价时间、价格及保护线。

`intraday_stop_alerts` 保存通知前的证据、确认状态与发送尝试；不是成交账本。同次检查合并提醒，
已受理的同一成本触发不刷屏。失败前3次至少间隔3分钟，此后已确认成本警报每小时重试，直至受理或退出持仓。
其他当日健康/疑似提醒最多3次；发送结果不明时重试可能重复。服务商受理不等于手机已收到。
数据、成本或结构保护线缺失会明确发监控降级提示；日历不可用不能按工作日猜开市。

Server酱免费版每日最多5条，与其他晚报共享额度；合并不能消除用尽额度的风险。未核验用户会员状态，
不自动订阅或购买服务。官方限制：[Server酱FAQ](https://sct.ftqq.com/docs/getting-started/faq/)。

## 本机安装与限制

用户明确授权后，在项目中执行：

```sh
.venv/bin/python -m ashare_lab.cli.intraday_risk install --yes
.venv/bin/python -m ashare_lab.cli.intraday_risk status
# 显式发送一次启用测试（占用当天一条额度，不是模拟止损；同次安装不盲目重发）
.venv/bin/python -m ashare_lab.cli.intraday_risk test-notification --yes
# 单独授权只用持仓代码核验公司行动
.venv/bin/python -m ashare_lab.cli.company_actions authorize --yes
```

独立任务 `com.zerong.asharelab.intraday-risk` 每60秒唤起。活跃持仓的交易时段保持进程运行，
防止正常闲置睡眠；不修改电源设置，合盖/关机仍不能监控。每轮子进程硬限90秒，使用自己的锁，
不受 `daily-sync.lock` 阻塞。异常后尝试单独的受限中断通知，所有 SDK/凭据原始异常均不输出。

本机目录：应用数据目录下 `scheduler/intraday-risk/`。配置、最近状态及日历缓存均为本机私有文件，
凭据只从钥匙串读取。交易日历优先现有免费 Tushare，备用 BaoStock；每个调用有隔离进程时限。

断网也可能使“断网提醒”无法送出；行情、轮询、微信延迟、T+1、停牌、跌停及跳空可能造成漏过瞬时价
或实际损失超过8%。一分钟只是检查目标，不是时延、成交价格或盈利保证。重要持仓宜同时在券商应用
设置到价提醒；本项目不代设券商提醒、不接触账户或自动下单。
