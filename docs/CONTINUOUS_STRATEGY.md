# 连续组合合同 · continuous-signal-v1

版本定位：单组、信号驱动、无强制到期，收盘后研究、人工执行。此文是当前连续组合口径；
[六期限旧版](../README_LEGACY.md)只作历史对照。实现仍属研究用途，未完成盈利有效性验收。

## 信号窗口不是持有期限

`CONTINUOUS_SIGNAL_CONTRACT` 独立冻结日线/完整周线窗口，见
[continuous_signals.py](../src/ashare_lab/analytics/continuous_signals.py)。兼容字段 `holding_weeks=4` 不代表到期卖出。
当前参数为：周线方向均线 8/26；日线结构回看 60、近期突破 10、底座 30、最大宽度 18%；
日线执行回看 40、近期 10、均线 20，日线锚 60，相对强弱 20，最少历史 140 个交易日。
组合风险与收益代理另用 20 交易日窗口及其历史样本量要求；每天复核不等于每天换股。

## 所有新入股先过同一门

初建和替补均要求 `EARLY_UPTREND`，并排除过热、末端加速，满足慢周期与结构资格，
主结构为确认突破或健康回踩，日线执行也须完成确认。接近突破、等待重新站回只观察。
健康回踩须有合格突破底座、突破后的完整路径守住允许区间，并真实触及后站回；不能只看最后一天。
早期分类包含均线有序上行、正趋势及 120 日涨幅 ≤15% 等条件；完整公式仍以版本化模块为准。
该阈值是未验证假设，不识别绝对底部，不证明先前必为熊市，不预测以后一定进入主升浪。
`ORDERLY_UPTREND` 的趋势可能良好，但不被自动改称“早期”。改变阈值须新版本和独立比较。

## 结构保护与旧仓管理

先取得当时可知的结构保护线，再校验计划入场价至保护线的距离 ≤8%。
区间计划按买入区间上沿衡量，保护线包含实际缓冲；不为满足 8% 修改结构位。
计划还冻结最高买价；实际开盘超限不追，失效、停牌或无法成交不能假设已买到。
8% 是初始计划距离，不是整个账户的硬止损，也不是实际最大亏损保证。
已有保护线只随确认结构上移；同日重算、模型切换均不能降低存储线。

旧仓使用固定日周线复核，不重跑新买资格，不因排名降低、趋势成熟或旧周期到期就卖出。
`HOLD / TIGHTEN / REDUCE / EXIT / REVIEW` 分别表示保留、收紧、减仓复核、退出建议、证据待核验。
公司行动区间不完整时不能确认退出或写入新保护线。完整收盘触发也仅供下一可交易时段人工决定。
推荐退出不改持仓账本；**卖出成交及实际现金未确认前，禁止把条件补位当作正式新买计划**。
可能存在 `pending_exit_symbols` 的本地条件预案，必须明确其前提，不能冒充已经空出仓位。

## 锁定旧仓，与现金一起比较

已有股票按实际固定股数与现金重估漂移权重，不强行取整、平均或再平衡；补位只用已确认可用现金。
所有保留股加候选须共同满足：最多 5 股、每行业一股、单股总资金 ≤30%、行业 ≤40% 及周期敞口上限，
并核验下行波动、回撤严重度、5 日 ES、下跌相关性与单股下行风险贡献。
风险贡献基准门为 45%，不因只剩 1–2 股而放宽；一股风险贡献为 100%、两股至少一股 ≥50%，
因此这些状态可如实保存，却可能必须先复核而不能补位。零股闲置现金不是虚构的零风险股票。
旧仓本身超限或证据不足时暂停补位；必要时需另提旧仓减仓建议，不能靠塞入新股掩盖问题。

| 阶段 | 搜索和仓位 |
|---|---|
| 初建 | 前 36 候选、beam 128，近似搜索 3–5 股；初建 10% 档在股票仓内 |
| 补一只 | 枚举全部已通过入场门的替补和总资金 10%/20%/30% 档，旧权重锁定 |
| 等待 | 留现金始终是选项；缺候选、无资金或无合格改善都不强行补齐 |

初建是受限近似搜索，不是全市场全组合穷举；单补位遍历全部已合格输入，也只是固定旧仓问题的比较。
共同历史窗口内比较 20 日净收益 LCB，精确旧权重用于固定股份＋现金路径，不能改成每日等权再平衡。
LCB 是历史均值减不确定性项；配置成本是历史账户扣减代理，不是逐笔真实换手成本模型。
它不等于夏普最大化、未来收益最高或动态策略已经获利；候选缺数据逐项记录，不能伪造相关性或收益。

## 账户快照与证据

当前组合 `metadata.account_snapshot` 需要以下显式字段，全部留在本机：

| 字段 | 要求 |
|---|---|
| `as_of` | 基准完整交易日，不晚于本轮截止，不早于任一当前持仓入场日 |
| `user_confirmed` | 明确为 `true`，不是从推荐或截图猜出完整账户 |
| `account_weights` | 覆盖全部且仅覆盖当前持仓，值为总账户比例 |
| `reference_prices` | 同一批股票的基准收盘价；须与基准日数据匹配，不用成本价替代 |
| `cash_weight` | 明确的闲置现金比例，与所有股票权重之和为 1 |
| `no_external_flows_since_snapshot` | 明确确认基准后没有外部入金/出金；未知则暂停 |

任何实际成交、入金、出金或股份变化都需要重新确认完整快照，不能沿用旧比例冒充新账户。
计算为“原账户权重 × 当前价/基准价”，再与原现金一起归一化；不推断股数或额外现金流。
持仓复核须与当前组合版本、股票集合、逐行版本及 `position_key` 一致，不接受重复或混版行。
公司行动记录需有来源和证据标识，以及 `company_action_clear=true`、`company_action_clear_from`、
`company_action_clear_through`；连续持仓动作要求从入场日起覆盖至本轮截止，漂移重估须覆盖快照区间。
缺失区间不能拿“本日未发现公告”代替；价格、计划、复核与行情共同截止不一致时不生成新买。

## 连续业绩单独记账

[continuous_strategy_journal.py](../src/ashare_lab/services/continuous_strategy_journal.py) 使用独立、追加式本地表，
不改旧六期限预测、到期统计或真实持仓。决策不是成交，服务商受理也不是成交。
实际模式仅接受用户明确确认、证据完整的整账户收盘快照；影子模式与实际模式分开，不互相替代。
记录须包含全部持仓单位、价格、现金、费用、分红、成交/公司行动/价格/外部流完整性、证据区间和标识。
费用、分红与外部流即使为零也须显式给出。未平仓浮盈亏和现金都计入净资产，不能只统计已卖出的赢家。
首个合格正净资产快照令净值为 1，不代表已有收益；此前表现未知。
v1 只计算明确零外部现金流的连续净值；非零或未知流不冒充投资收益，不偷偷重新定基。
缺输入或证据的快照为 `unavailable`、收益为空；中断后的新基准须显式新建记录链。
它是记账基础，不是已经接通券商成交、每日自动补齐实际快照或完成动态策略回测的声明。

## 运行与交付边界

北京时间周日至周四在 21:00、21:15、21:30、21:45 最多四次尝试；明天须经核验是交易日。
周五、周六无常规计划；收盘数据是否完整仍由独立更新和核验决定，不由时钟决定。
默认仅 Server 酱；持仓文字授权、图表授权、R2 私有发布凭据独立校验，不把外部平台视为私有账本。
日周图与文字对齐同一持仓版本及截止，辅助线从证据可知时刻开始。图片失败不能伪装图片已送达。
末次失败可提交故障提醒；服务商受理和本机测试都不是手机收到的证明。

严格样本外验证仍缺真实时点股票池、成交约束、费用滑点、分红除权一致口径及连续动态路径验收。
不得以本轮代码测试、样例演算或历史 LCB 宣称盈利、收益优势或未来全市场最优。
MCP `generate_portfolio` 与旧六期限接口仅为固定期限对照；新旧归档和业绩必须分版本解释。
私有行情、账户快照、数据库、报告、密钥和签名图片地址不进入开源仓库。
