# 全流程审视：逻辑、风险与盈利证据

审核日期：2026-09-05。对象是本项目实际的中期主链、定时任务与私有档案，
不是父目录其他交易实验。以下明确区分已修的工程缺陷、已同意的规则和仍待验证的假设。
不公开个人持仓、原始行情、私有运行日志或凭据。

本轮最终离线回归：**952 项测试通过**，代码静态检查通过；覆盖新增买价上下界、
不可变结算、六期限主链和精简通知。验证没有连接券商、执行真实结算或提交微信消息，
也没有生成可用来证明盈利的样本外收益。

## 结论

保留低频、分期限、确认后介入、去弱留强、退出先留现金的框架。这和收盘后研究、由人
执行的使用方式相容。但“逻辑有道理”不等于“扣除成本后有持续正收益”。
本项目尚不能自称已验证盈利、全市场最优组合或完整复刻麦基基准点法。

现有组合比较是先选本次候选，再计算这些证券的历史组合风险和持有期收益下界。
它不是在每一个历史决策日重新选股、模拟可成交买卖后得到的样本外策略表现。
六个期限与相邻日期可能持有相同证券，这些结果不能重复当作独立成功样本。

## 已敲定的个股风险规则

1. 从当时已确认结构确定含缓冲保护线，不先定一个亏损比例再倒画技术支撑。
2. 新介入按计划触发价或买入区间上沿计算风险。若 `(买价−保护线)/买价 > 8%`，
   或保护线缺失，则等待或放弃，不进入可介入组合。
3. 计划最高买价不高于 `保护线 / 0.92`。超过最高价或成交前已经跌破保护线，都不能按
   新计划模拟入场；原触发记录保留，该份额留现金。
4. 持有后的有效保护线只随已确认结构抬高；失效在先，不必等亏满 8%。
   新候选排名下降本身不是卖出理由。
5. 淘汰对象是失效个股，不是因为其中一只触线就抛弃全部健康持仓；退出后先留现金。
   替补仍须通过独立新计划。研究结论不会替用户修改实际持仓。

8% 是新交易计划的个股价格风险上限，不是已证实最优的参数，也不是账户回撤上限或
成交保证。程序按收盘复核，没有盘中自动止损；次日跳空、停牌、涨跌停、T+1、费用与
实际成交价都可能使结果偏离计划。已持仓不能事后假装按新版本进入。

单笔对账户的计划损失近似为 `总资金权重 × 入场至保护线的距离`。
例如占账户 20% 的一只股票损失 8%，对账户影响约 1.6%，未计费用及成交偏差。
多个行业也可能同时下跌，不能用行业数量替代总风险预算。
保护线与头寸规模应一起确定，而非任意设置止损。参考
[CME：持仓规模与风险](https://www.cmegroup.com/education/courses/trade-and-risk-management/proper-position-size)。

## 尚未解决、不得用文档假装完成的事项

- **公司行为和双价格口径。** 当前历史主链为未复权数据；除权分红、拆送股的变化可能
  污染趋势、风险和收益。独立公司行为覆盖尚未持续接通，持仓保护线因此可能仍待核验。
  缺证据必须继续阻止确定退出结论与正式收益解锁。形态价格和真实可交易报价需要有
  时间边界的转换，不能把前复权价直接当订单价。
- **持仓绑定初始计划。** 实际买入日期/成交价可能晚于原计划；登记时应再次验证风险，
  并绑定当时合法保护线。单有新计划 8% 校验不代表旧持仓已自动满足这条规则。
- **完整交易日历。** 周/月线部分路径仍保守使用周五/工作月末；节假日封口和麦基影子
  的完整交易日证据未全部接通。影子记录不因此获得可评价资格。
- **完整净收益回放。** 固定到期价格表现不是途中止损、现金、替换后的净收益。尚缺
  全面的逐笔成本、涨跌停/T+1可执行性以及点时点全市场重选的样本外回放。
- **月报外发。** 当前月复盘仍以本地归档为完成边界，尚未形成独立微信发送去重闭环。
  基准接入不等于月报已经送达。历史到期时钟仍兼容旧交易日，新自然月口径须显式标记。
- **研究参数。** 周/月独立过热校准、每行业最多一只、早期转强优先及账户损失预算等
  都不能以新的随意阈值直接替代验证。

这些项目未完成前，状态保持研究/部分整合，不把“有输出”解释为“完整可执行”。

## 如何判断它是否真的值得使用

优先验证实际采用的一个月策略，再扩展其他期限。先固定规则、买卖时点、费用、基准和
评价指标；不能看完测试结果再挑参数。回测反复选优会增加虚假发现风险，参见
[Bailey 等：回测过拟合的概率](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。

验证分为三道门：

1. **账算对。** 构造小行情验证跳空越过最高买价、跌穿保护线、T+1、不能成交、公司行为、
   部分未入场及现金保留。失败股票不得从原推荐记录删除。
2. **历史重放可信。** 在每个历史时点重建当时股票池、退市/ST状态、行业与已公布信息；
   参数仅使用训练段，剔除跨训练/测试边界的重叠持有标签，保留从未调参的最终区间。
   分多个市场状态报告净收益、最大回撤、最差阶段、换手、成交失败及不确定区间。
3. **前瞻记录经得起检验。** 从发布时冻结每期计划，同时保留“原推荐持有到期”和
   “按退出规则执行”的两套成绩。月度复盘事实，修改需要新版本与用户确认，不因一个月
   输赢自动调参。不把每日高度重合的推荐当成独立试验。

早期转强与整理后延续突破应在同样数据、成本和风险预算下分别比较。
优先关注靠近有效结构、风险可控的介入；不能只因价格低就认定安全，或只因接近新高就
断定没有价值。两条路线谁更适合本项目，要由上述证据决定，不能由“图形看起来好”决定。
