# 推荐股票生命周期跟踪

自 2026 年 10 月 8 日起，独立跟踪已正式发布的买入推荐，不要求用户实际买入。
这是一套**模拟价格表现账本**，与真实持仓、账户收益、旧六期限到期组合完全分开。
无合格股票的日报也保留；观察候选不冒充正式买入推荐。

## 样本和执行口径

每份原始报告必须有发送服务商受理回执，且决策内容通过哈希核对。服务商受理不等于
手机已阅读。保存报告日期、数据截止、原始版本、每只股票的结构化买入条件和首次发布时间。
旧报告缺少结构化条件时明确标记缺失，不按后来涨跌倒填条件或成交。

每日重复推荐保留每次提及，但已在跟踪的同一段持仓只计算一次收益，不重置成本。
退出以后出现新的推荐，或者旧日计划未触发而新日重新推荐，建立新的研究机会。
未触发、亏损、尚未退出以及证据不足的记录全部保留。

当前研究执行模型为 `recommendation-lifecycle-v1`，使用已核验的未复权日线：

1. 买点先等待完整日线确认。健康回踩需要触及归档区间，收盘站回区间上沿且不低于开盘；
   重新站回关键位需要收盘达到归档触发价；放量突破还须达到原始成交量或成交额阈值。
2. 确认后的下一个交易日，按开盘价模拟入场，不能高于原买价上限，也不能低于或等于结构保护线。
   不假设买在当日最低价或已经知道完整日线的同一收盘价。迟发报告不追溯使用发布前的行情。
3. 当日未触发的计划到期失效；这只是入场计划的有效期。已经模拟入场的股票**没有固定持有期限**。
4. 成本止损线为模拟入场成本的 92%。盘中最低价触及即记触发，不因收盘反弹而撤销；
   跳空低开按更差开盘价模拟，入场当日触发按 T+1 延至下一可交易日。
5. 日线收盘跌破预设结构保护线，下一可交易日开盘模拟退出，不等反抽，也不等周线收盘。
   已完成周线的确认低点与既有 ATR 缓冲用于上移保护线，保护线不下调。
6. 无量、一字价格、缺行情或公司行动证据不全时，不假装可以买卖。
   除权、分红、送转、配股改变价格基础的区间暂列待校正，不把原始价差冒充总回报。

这是一个固定、可复算的日线执行假设，不是逐笔实盘回放。日线不能证明止损价一定有足够
对手盘；实际滑点、费用、涨跌停排队及 T+1 都可能使真实结果更差。模拟不能保证亏损封顶 8%。
回踩企稳的机械确认用于此独立研究执行模型；不会偷偷替换实际选股评分或放宽原始推荐门槛。

## 每只股票记录什么

| 字段 | 计算或口径 |
| --- | --- |
| 计划买点 | 原始区间、触发价和参考价；与模拟成交价分开 |
| 模拟入场和退出 | 日期、价格、触发原因、规则版本 |
| 每股价差收益 | 模拟退出价 − 模拟入场价，元／股 |
| 收益率 | 退出价／入场价 − 1 |
| 持有交易日数 | 入场日至退出日，首尾两个交易日均计入 |
| 持有自然日数 | 首尾日期均计入；不以自然日替代交易日 |
| 日均收益率 | 收益率／持有交易日数，算术口径 |
| 等效日复合收益率 | (1 + 收益率)^(1／交易日数) − 1 |
| 尚未退出 | 仅展示最后核验日的浮动价差，不混入已退出收益 |

不编造股数或投入金额。收益是未计费用和分红的模拟价格收益，不是实际账户收益；
各股票平均收益也不是组合资金收益，不用于直接宣称策略净值或夏普率。

## 每日运行与复盘

日报成功交给推送服务商后，先本地登记；数据更新并通过共同截止日核验后，自动重放和存档。
登记失败或行情／公司行动暂不可用会留下状态并在后续运行重试，不阻塞主日报发送。
原报告和每轮结果不可覆盖；输入变化形成新观察，旧证据仍可追溯。

每轮记录已完成、未入场、持有中、证据缺失等完整分母，并标记超过止损触发损失等异常。
样本少时不能判定某种买点“更好”；即使达到复盘样本提示阈值，也不等于统计上已证明有效。
后续改进需要区分买点类型和市场阶段，保留亏损样本，并做独立样本验证及费用敏感性检验。
**系统只形成复盘线索，任何买卖规则或阈值更改均须先与用户讨论确认。**

沿用已安装的数据同步任务，不新增微信固定推送，也不启用打板或自动交易。
本机任务依赖机器、网络和数据服务可用；代码入库不代表已部署到常开云服务器。

## 检查与回填

在项目环境中运行：

```bash
python -m ashare_lab.services.run_recommendation_tracking --through 2026-10-09 --backfill
python -m ashare_lab.services.run_recommendation_tracking --status
```

结果写入应用私有数据库的 `tracking_reports`、`tracking_runs` 与公司行动证据缓存。
不修改真实持仓表，不重启旧按周、月、季到期结算。数据库、行情及私有结果不提交 GitHub。
