# 马克斯启发的周期风险层 · 影子运行

`marks-cycle-shadow-v1` 是参考霍华德·马克斯思想的研究实验，不是原书公式、
精确牛熊定位、未来收益预测或已验证的仓位模型。生产仍使用 `continuous-signal-v2`。

## 分工

- 周期风险：评价估值、盈利、信用压力、情绪拥挤；关注极端，而非天天预测转折。
- 个股执行：日线与完整周线的早期转强、底座突破/健康回踩及既有保护规则。
- 组合构建：锁定已确认旧仓，比较替补与现金，保留行业和下行风险约束。

便宜、恐惧不等于立即买；昂贵、乐观也不自动触发全仓卖出。主升浪无法预知。
新层不改持仓、不放松 8% 初始风险距离、不抬高原有仓位上限、不发第二组推荐。

## 四类证据与时间

| 维度 | 指标输入（0–100） | 最大观测年龄 |
|---|---|---:|
| 估值 | 明确口径、参考样本的历史估值百分位 | 14 自然日 |
| 情绪 | 明确口径的情绪/拥挤百分位，越高越热 | 7 自然日 |
| 信用 | 明确口径的信用压力百分位，越高越紧张 | 62 自然日 |
| 盈利 | 固定可比样本中盈利改善企业比例 | 125 自然日 |

必须有公开 HTTPS 来源、发布者、观测截止、发布时间、抓取时间、指标定义、参考窗口、
样本数；百分位不能由语言模型凭叙述打分。进口记录时间由程序当场生成，不能回填。
历史重放只使用当时已经抓取并登记的证据。观测不能晚于行情共同截止日。
不同来源可不同频，但超龄或缺失不当成中性，不补零，不沿用过去的“进攻许可”。
时间戳字段和链接存在只证明格式合格，不证明事实真实；输入需要独立研究核验。

**当前没有自动抓取完整四类时点证据的生产连接器。** 模块支持经审核的本地证据导入；
没有这些输入时，每日晚报构建路径仍运行并归档 `data_not_ready`、缺项和空仓位建议字段。
这不等于系统已经能凭当天新闻完整实施马克斯方法，更不冒充四类数据已经接通。

## 冻结的实验规则（不是马克斯给出的数字）

按以下顺序：

1. 估值与情绪均 ≥80：过热防守，影子上限 30%。
2. 信用压力 ≥80 且盈利改善比例 ≤40：信用压力防守，影子上限 30%。
3. 估值与情绪均 ≤20：机会观察，影子上限 50%，不提供买入许可。
4. 估值 <80、信用压力 <60、盈利改善比例 ≥60：修复进攻，影子上限 80%。
5. 其余完整但混合的证据：基准观察，影子上限 50%。

最终影子上限取上述上限与现行价格周期上限的较小者。上限不是目标仓位，
剩余现金下限也不是实际账户现金；影子值不送入真实组合构建。
普通状态变化按自然周冻结；周内更严格的风险上限可立即收紧。资料缺失仍立即失效。
这些阈值、年龄和周度冻结都须在固定历史时点样本外验证，不能按单次收益调参。

## 本机审计与操作

本机 `research.db` 中独立的 `marks_cycle_evidence`、`marks_cycle_runs` 追加式表保存证据、
哈希、覆盖度、原上限和影子上限差异；同输入同时间重跑幂等。数据库触发器禁止覆盖和删除，
这不是抵抗数据库管理员篡改的外部存证。原持仓、历史推荐和保护线不改写。
现行晚报只携带内部审计引用，不向 Server酱外发影子指标、原始数据或冗长周期审计。

```bash
# 导入已经独立审核的公开指标文件；文件属于本机私有数据，不能提交 GitHub。
.venv/bin/python -m ashare_lab.cli.marks_cycle import-evidence /absolute/path/evidence.json
```

每项 JSON 严格包含：`dimension`、`value`、`observed_through`、`published_at`、
`retrieved_at`、`publisher`、`source_url`、`metric_definition`、`reference_window`、`sample_size`。
维度名见 `analytics/marks_cycle.py`；不得附入密钥、持仓或原始许可数据。
生产晚报构建会自动做本地影子归档。独立 `run --price-cutoff ... --incumbent-cap ...`
只适合明确记录假设的本地实验；手工上限不代表当日现行模型实测值。

## 何时可正式影响仓位

先接齐合法、可追溯的四类时点证据，再在相同股票池、费用、滑点、交易约束下，
比较“原策略”与“原策略＋周期层”的滚动样本外表现：收益、回撤、尾部损失、换手、
现金拖累、最差区间和置信区间。影子上限差异不是账户收益，不凭空模拟已成交。
有充分证据后与用户讨论，单独批准和升级策略版本；本次不自动晋级。
